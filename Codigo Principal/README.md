# Entregas del proyecto

En esta sección se reúnen las **tres entregas** del proyecto de construcción de software para la Boutique UADY en línea. El contenido de cada entrega se organiza en sus respectivas carpetas para facilitar su consulta.

La carpeta **segunda entrega** contiene el código correspondiente a esa etapa. Este README sirve como guía de entrada para identificar el propósito de la sección antes de abrir una entrega.

> Las carpetas y los archivos de la boutique se mantienen sin cambios.
